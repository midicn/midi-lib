## 五、质量工作原则（本项目内约定）

1. **自动规则必须有排除名单**：任何批量归并/过滤规则都要配 `EXCLUDE` 白名单，防止误伤
2. **先 dry-run 再写回**：所有批量写操作先 `--dry-run` 人工审查输出
3. **变更必留档**：写回前快照 `midi_trash/<描述>-<时间戳>/`
4. **可复现**：任何一步效果都可用脚本重跑（state 断点 + 确定性排序）
5. **并发警惕**：同一数据目录不得同时读写（曾因并发导致 JSON 半写错误）
