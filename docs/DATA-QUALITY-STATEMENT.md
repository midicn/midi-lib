## 二、信任边界（我们无法逐一承诺的部分 · 诚实披露）

### 2.1 与原乐谱的音符级比对（唯一保留的未验证项）
- 本库的 MIDI 来自公开数据集的既有转录。我们完成了**统计级验证**（上表第 11 项：调性/动机/密度等音乐学特征全量检测，能发现乱码、损坏、转录断裂类问题）。
- 但**逐音符与原乐谱比对**（验证每个音高/时值的转录误差）需音乐学人工核听，仍未执行。
- **含义**：数据不存在「损坏/乱码/空文件」级问题（已程序化排除）；个别曲目可能存在转录误差（错音、省略反复），这继承自原始数据集。

### 2.2 元数据继承
- `title / opus / form / key` 等元数据**信任原始数据集**。ariamidi 无曲名（title 覆盖率 65.6% 的主因）； Essen/thesession 的曲名为源库原文。
- 作曲家署名信任源数据集。**已知的系统性问题已修正**（表演者误标为作曲家、10 处归并误伤），但 2,094 个「1–2 首」的长尾署名未逐一人工考证。

### 2.3 链式许可
- 我们核实了**各数据集自身的许可声明**（CC BY / CC BY-SA / PD 等）。
- 但对**上游转录者是否确实有权按该许可发布**（如 ariamidi 的转录来源乐谱版权状态），我们**无法穿透验证**。已按最保守策略分区（存疑内容全部排除或隔离）。

### 2.4 指纹去重的残余风险
- 361 组「仅同作曲家」的指纹相似对**未处理**（可能为同曲不同版本，也可能为不同曲子）——已输出至 `dedup-pending-review.md` 供人工复核，**宁保留不过删**。

## 三、使用建议

1. **发布主库**（`main` 分区 48,154 首）可放心使用；`piano-special`（CC BY-NC-SA）与 `research` 仅限非商用场景。
2. `pending`（chinafolk 10,473 首）**许可未确认，请勿发布**——待作者授权确认后转正。
3. 对音乐学准确性有严格要求的场景（如学术研究），建议对所用曲目做人工核听。
4. 发现数据问题时请反馈至项目仓库，我们按「审计→修复→重审计」流程处理。
